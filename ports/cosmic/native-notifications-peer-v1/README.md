# COSMIC notifications peer lifecycle v1

Applies one runtime source patch after the frozen static-v2 source export. The original upstream commit, Cargo manifests, locked resolution, GUI/a11y/X11 features, SDK and resource envelope are unchanged.

The optional panel peer waits for first traffic before its existing one-second authentication deadline. Its abort-on-drop task owns the connection independently of public notification registration. Runtime evidence is separate from build admission.
