# V0.20 SnapshotCatalogStore 目录候选

物理块 `4131` 的前 40 字节采用 G1 D1.5 CatalogStore 信封。整块 CRC32C 覆盖下列候选载荷，
计算时将信封 CRC 字段置零。整数按小端编码。候选从偏移 40 开始包含一个头和八个固定槽目录项。

| 头内偏移 | 候选字段 |
|---:|---|
| 0、4、6 | `u32` 魔数 `0x43594344`、`u16` 版本 `1`、`u16` 头长 `24` |
| 8、10、12 | `u16` 行长 `96`、`u16` 槽数 `8`、`u32` 非空槽数 |
| 16 | `u64` 下一快照 ID，所有现存快照 ID 均小于此值 |

| 行内偏移 | 候选字段 |
|---:|---|
| 0、1、2、4 | `u8` 状态、`u8` 类别、`u16` 槽号、零保留 `u32` |
| 8、16、24、32、40 | `u64` 槽代际、快照 ID、捕获视图 epoch、捕获提交 LSN、创建在线时长 ns |
| 48、52 | `u32` 描述页块号、`u32` 业务 inode 镜像首块号 |
| 56、64 | `u64` 根删除提交 LSN、整张 4096 B 描述页的 32 B SHA-256 |

八行依槽号 0–7 排列。槽 0–5 的类别为定期 `1`，槽 6–7 为按需 `2`。末行之后至块尾全零。
`FREE=0` 只保留槽号、类别、槽代际。`ACTIVE=1` 的根删除 LSN 为零。
`DELETING=2` 保留对同一不可变描述页的绑定，根删除 LSN 严格晚于捕获 LSN。
保留截止和保护状态由 SnapshotProtectionStore 持有。

校验上下文来自同一静默读视图，提供已选卷 UUID、目录和 SlotStore 代际、视图 epoch、已提交 LSN
及在线时长。目录校验拒绝重复快照 ID，并要求非空行指向 `4132 + 15 × slot` 及其后一块。
每个非空行交由独立槽校验器核对整页摘要、卷和捕获身份，再校验按物理地址读取的 14 页镜像。
槽 0 空闲时，读取共享 SlotStore 信封来核对容器 UUID 和代际。目录已解除对退役描述页的引用，
即使原字节仍留在槽 0，也只核验信封，跳过它的镜像。最大读取量为 120 个槽块。

```sh
python3 -B tools/v020_snapshot_catalog_vectors.py check
cargo test --locked -p cyxia-kernel-core --test snapshot_catalog_candidate
```

39 个独立向量覆盖单槽、双槽、八槽、删除中、回收后水位、跨卷及代际不一致。
Rust 与 Python 对合法目录逐字节重编码，并核对每个向量的实际块读取序列。
候选仅在宿主端编译，生产挂载继续验证已批准的空载荷。目录树、数据归属、历史读授权、
事务发布与 GC 仍需各自的 D7 证据。
