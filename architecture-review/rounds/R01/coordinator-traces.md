# R01 协调者跨域推演

输入为 baselines/R01 两份设计。以下为文档机制推演，不是运行测试。

| 场景 | 事件轨迹与已有防线 | 当前结论 |
|---|---|---|
| 周期边界/恢复 | 控制窗口到期→DEGRADED→维护→SELF_TEST；同一账本不刷新，周期尾部拒绝入场 | §7.2/7.3、§9覆盖额度重复发放；初始化实际闭环交通道C核查 |
| 提前/迟到唤醒 | wait g登记→消息先完成→提交BLOCKED重查；旧g消息到新g时被拒绝 | §10.6.4 WaitCell保存结果，Placement→WaitCell提交避免丢失 |
| 满队列 | 远端WAKE遇收件箱满→pending位→调度点扫描；阻塞任务不释放归属额度 | §10.6.4提供持久事件与准入基础 |
| ACK丢失/回滚 | PREPARE→MIGRATING→目标COMMIT→ACK丢失；源查询owner不重新入队 | §10.6.5唯一归属与回滚槽；取消等更多交错由B审查 |
| 页撤销 | 修改mapping_epoch→取得active集合→失效ACK→回收；新进入空间受锁与代际检查 | §10.6.7禁止收到全部确认前复用旧页 |
| IPI与锁 | IPI中断可能持锁的路径→只登记事件；不在归属锁内等远端 | 锁规则已有；有界性是否足以抵御持续中断由A审查 |
| 未知协议/溢出 | 版本、长度、保留位错误→拒绝；固定结构与模型维度 | v1为64字节、1396参数、86016 MAC核算一致；整数缩放闭合由C核查 |
| 全局协调预算 | N核每核1ms/10ms→协调器从既有额度划拨→分母N核CPU | §10.6.3和§10.5没有为新增协调器自动加总额度 |

所有域仍须等待独立通道结论，不凭本表将整体审核标记为通过。
