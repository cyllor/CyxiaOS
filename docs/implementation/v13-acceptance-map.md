## 最小、不能由应用或模型自行宣告成功的原生证据链

这里的“不可伪造”只能指在受信构建镜像/内核及独立判定器边界内，不允许普通业务或模型伪造回执。没有远程度量硬件，不能声称抵抗被篡改内核或恶意宿主的绝对不可伪造证据（§10.1明确限制）。

1. **冻结构建身份**：DOCX hash + 机器Schema/模型/包hash + 提交/脏补丁hash + §1.2完整工具/QEMU/DTB/启动清单；本地离线训练输出与客体运行目录分开。启动每台QEMU时记录PID、命令、独立磁盘文件与初始hash、NodeID/MAC/IP；不输出私钥。
2. **原生事实起点**：每CPU从真实异常级、DTB/启动方法进入的内核事件；独立EL0地址空间/角色/能力；每次BootEpoch持久提交的事务完整键、设备FLUSH完成与发布门开放顺序。源码静态常量或宿主脚本打印“EL0/4CPU”不计。
3. **受保护完整事件流**：内核独立递增序号和客体单调时钟，记录任务实际switch-in/out、CPU、EL、角色、C/B/T/Q/core_gen、draining/suspect；IRQ实际CPU、IPI/静默/TLB ACK请求ID与CPU代际；页、描述符、预算、credit的reserve/consume/release事实。任何关键序号缺失/overflow应阻止新相关授权并使本次证据不完整，不能默默采样。
4. **模型→动作**：冻结快照原值/Schema→完整候选原字节与索引→每候选完整整数得分及稳定输出→PlanID/DecisionKey/模型代际→EL1校验/预留/PUBLISH版本→真实执行器inflight/APPLIED或拒绝→实际硬件/调度行为。登记执行器身份+代际+完整apply_id由内核授权，测试业务伪造APPLIED必须被拒绝。真实1→2→1要由实际调度/IRQ轨迹和核心PUBLISH证明，不能只看mask字段。
5. **双节点因果链**：两端各自原生TLS当前会话标识/boot/challenge绑定→持久CONFIRMED→各自保存同一双签Config/CommitProof→STATUS对账完→主动READY收发门→QUOTE→PREPARE全部资源预留→COMMIT持久GRANTED→START_PENDING+STARTED意图落盘→最终启动门→唯一任务运行队列投递/执行→终态正文+hash同事务持久→请求方持久接收→ACK_RESULT→所有者持久ACK再正文回收。每个箭头有真实调用者、记录键/摘要和执行器证据；双方时钟只比本地因果与区间，不比较跨节点绝对monotonic。
6. **外部可重放故障与独立判定**：宿主可截断链路、杀QEMU、控制未FLUSH写丢失/撕裂；注入器日志只证“注入”，客体日志/原始磁盘证“结果”。独立只读磁盘校验器验证黄金镜像/提交链/墓碑/结果保管；另一个判定器从原始事件重建所有权和容量，不能读测试程序写下的PASS布尔值当证明。串口日志文本、host模拟状态机/单元测试、密码向量与原生系统运行分别标注evidence_kind，互不替代。
7. **用例证据包**：test_id+clause、全部hash、seed/冻结初态、注入点及时刻、完整快照/决策/计划/对象/执行器代际、原始轨迹、明确断言、原始指标、判定器版本、PASS/FAIL/NOT_RUN与原因。建议保存sha256清单及判定输入路径，任何缺项为NOT_RUN或明确执行失败；不能把BLOCKED/host-test-pass转换为native PASS。

最小冒烟可以是A01/A02/A03与A12/T01/A13/T11的正常路径，但它只能证明这些子场景存在；控制隔离和双节点边界“完成”仍需上面全部关联故障断言。

## 实施依赖顺序与分阶段出证据

1. **契约锁定**：记录用户已批准Rust功能路线及§1.2语言偏离；冻结1.3 doc/schema/test ID，建立独立1.3 catalog/证据清单，保留旧81项为legacy追踪；不迁移状态、不放宽其他约束。
2. **原生确定性根基**：启动/DTB/四核、异常切换、地址空间/能力/IPC、寄存器保存、计时、受保护追踪与独立判定；A01基础/A02/A06/A09/E05/E06/E08。
3. **进度与账本**：线程亲和子账、恢复池/credit、VirtIO block/net/rng/IRQ、SAFE_EXEC、真实FLUSH与文件日志恢复、BootEpoch持久门；A01故障/A10/A11/E02/E04/E15。原生双节点授权不能早于这一阶段。
4. **所有权与发布机制**：C/B/T/Q、draining/suspect、IPI/静默、不可迁资源、完整迁核事务、不可变policy根/对象desired/inflight串行/幂等ABI与回执；A04/A07/E01/E03/E07/E08/E13。先验证确定性状态机，再接模型；这些测试不能冒充A03的AI选择。

6. **原生网络与双节点**：native协议栈/TLS标准向量、独立身份和熵、发现、成员锁、READY、合同与最终启动门、结果保管/ACK、离群/重连；A12–A14、T01–T20、E09–E12，依赖步骤2–5，不用宿主代理替代客体服务。
