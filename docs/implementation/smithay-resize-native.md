# Smithay 锚定缩放与关闭期间的抓取清理

日期：2026-10-22。本文记录本轮设计与验收契约，实际结果在文末单列。

## 范围与分层

本阶段在 CyxiaOS 自研 ARM64 内核上，以真实 Smithay、libwayland 客户端、Mesa softpipe/GLES 和原生 VirtIO 显示接口验证左上角及左边缘缩放，以及按钮仍按住时关闭窗口的处理。通用几何模块实现八个 xdg 缩放方向；客体验收仅声明实际执行的左上角和左边缘。

`ports/cosmic/smithay-resize/geometry.rs` 处理有界授权、方向解析、固定对边的几何计算及提交事务；`main.rs` 连接实际 seat、配置确认、缓冲提交和窗口生命周期。已有独立场景模块 `smithay-multi/scene.rs` 提供堆叠、命中和几何更新，保持原接口与旧验证程序不变。新的客户端、构建入口和验证器使用独立 profile。

本阶段未运行 `cosmic-comp`，未实现动态客户端接入、通用窗口管理、Escape 取消回滚或未确认配置时连续移动的合并。关闭窗口时清理抓取不等于仍保留窗口时恢复旧缓冲与旧尺寸。

## 几何提交原则

缩放以开始时的矩形和指针为基准计算累计位移。左/上边缘改变原点并固定右/下边缘；右/下边缘保持原点；单边缩放不改变正交方向的尺寸。尺寸限制为宽 32–96、高 24–80，限幅后仍固定对边。中间运算使用较宽整数，结果溢出时保留原状态。

配置确认与实际匹配尺寸的缓冲提交完成后，位置和尺寸才一起更新。这个位置更新是一次性事务，普通重绘不能重新应用旧配置的位置，也不能忽略左/上边缘的新原点。错误尺寸和无效配置不得部分修改场景。

抓取授权仍来自实际 seat、按下事件序号与拥有事件焦点的客户端，输入和配置共用 Smithay 的序号分配器。协议和几何校验属于确定性机制；已有本地 AI 继续负责资源准入、CPU 派发和显示提交，不新增窗口布局模型，也不扩大资源额度。

## 关闭与剩余按钮释放

窗口在按钮按住期间关闭时，先移除交互及场景中的所有者，避免恢复已经移除的表面焦点。实际指针抓取转入无焦点的等待释放状态，继续接收物理按钮释放并更新 Smithay 的按键账本。所有按钮松开后才结束该临时抓取。

因此窗口关闭后的第一个场景允许仍有等待释放的指针抓取，但已没有活动缩放或被关闭窗口的指针焦点。后续背景释放必须清空该状态；不能直接丢弃释放事件，也不能依赖当前位置必须命中窗口，更不能把没有对应按下事件的释放发给剩余客户端。

## 十二个客体场景

128×96 画布位于实际屏幕 `(32,48)`。初始 A 为 `(24,16,64,48)`，B 为 `(40,24,64,48)`，B 在上并持有键盘焦点；指针 `(32,24)` 位于 A 独占区域。

| 场景 | 实际输入与协议行为 | A 几何或剩余窗口 |
| --- | --- | --- |
| 0 | 两个客户端初始提交 | A 初始矩形，B 在上 |
| 1 | 左键按下，A 激活，请求左上角缩放 | A 初始矩形，Resizing 开启 |
| 2 | 指针 `(-8,-4)`，配置确认并提交 | `(16,12,72,52)` |
| 3 | 指针 `(+12,+8)`，反向缩放并提交 | `(28,20,60,44)` |
| 4 | 左键释放，最终配置确认并提交 | `(28,20,60,44)`，Resizing 关闭 |
| 5 | D 键，A 普通重绘 | 新原点保持，不产生新配置 |
| 6 | 右键按下，请求左边缘缩放 | `(28,20,60,44)`，Resizing 开启 |
| 7 | 指针 `(-16,0)`，配置确认并提交 | `(12,20,76,44)`，上下边不变 |
| 8 | Q 键关闭 A，按钮仍按住 | 仅 B，焦点回退；等待剩余按钮释放 |
| 9 | 背景位置 `(20,28)` 释放右键 | 仅 B，指针抓取和按下账本清空 |
| 10 | D 键，B 继续提交 | B 响应帧 |
| 11 | Q 键关闭 B | 全黑，窗口和焦点为空 |

每次启动十二张实际 scanout、147,456 个像素、十五次 QMP 输入命令、十次客户端缓冲提交（A 八次、B 两次）与十一组配置确认（A 八组、B 三组）。主机根据独立的几何和像素公式检查实际显示，不以合成器自身的通过日志替代像素证据。所有并发协议记录包含换行且不超过 64 字节，使用一次真实写入。

## 构建和验证入口

服务端入口为 `tools/build_smithay_resize.py`，使用固定的源清单、fat LTO、已有 Mesa 静态 SDK 及构建预算。客户端入口为 `tools/build_smithay_resize_client.py`。内核 feature 为 `smithay-resize-probe`，环境变量 `CYXIA_SMITHAY_RESIZE_PROBE_ELF` 与 `CYXIA_SMITHAY_RESIZE_CLIENT_ELF` 分别指定实际 ELF。旧交互与 LXPanel 桌面仍使用各自的显式镜像配置。

该镜像的串口 shell 命令为 `posix exec smithay-resize-probe`，由验证器按十二个场景驱动实际键鼠输入；此入口不是可自由操作的桌面会话。

```sh
python3 tools/verify_smithay_resize.py \
  --elf artifacts/smithay-resize-kernel-r0/cyxia-kernel.elf \
  --server artifacts/smithay-resize-build-r0/smithay-resize.elf \
  --client artifacts/smithay-resize-client-r0/smithay-resize-client.elf \
  --output artifacts/smithay-resize-manual-check --iterations 3
```

输出目录必须尚不存在，以保留独立运行的原始证据。
