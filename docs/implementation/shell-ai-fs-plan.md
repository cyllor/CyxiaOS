# Shell 与 AI 文件系统实施切片

用户授权：实现基础 Shell 和 AI 强化文件系统。该切片提前实现原 M6 的可测试子集，不将 M2 用户态、多进程或完整 M6 标记完成。

## 范围与决策

- 串口交互 Shell，支持 help、pwd、cd、ls、mkdir、touch、write、append、cat、stat、rm、rmdir、df、ai status/cache/train/apply/rollback。
- 独立 no_std 文件服务和命令解释器，不依赖 ARM/MMIO。内核当前在 EL1 单线程调用，未来通过服务接口移至用户态；不宣称已有权限隔离或多核安全。
- 首先实现 RAM 文件系统：32 个目录/文件节点、每文件 1024 字节、路径最多 95 字节；重启清空，无磁盘持久化承诺。本轮按先实现 RAMFS 的默认范围交付，持久化另行实现。
- AI 文件域使用独立、有界的本地整数线性模型：写入准入、只读缓存排名。训练脚本从可复现合成样本拟合初始参数；明确不是大语言模型，也不是生产工作负载上的效果证明。
- 请求语义由操作员给定；AI_DIRECT 只表示实际模型策略。硬约束校验路径、类型、长度、容量、提案修订号与缓存候选合法性。不能回收文件正文以满足缓存策略。
- 文件域固定 BOOTSTRAP 内存预留上限 128 KiB（含文件、缓存、模型、样本、命令缓冲）；不借用未来 CPU 模型预算。无动态分配；每操作最多扫描 32 节点，模型固定维度，训练最多 8 轮 × 48 条样本。
- 学习由有界元数据样本驱动：每次读取固定两条成组样本，24 个事件训练（48 条）、8 个事件时间后置分类验证（16 条）；固定独立合成 canary 防护；验证候选后由操作员 apply，支持 rollback。模型状态与文件一样仅保留本次启动。

## 验收

1. Host 单元/集成测试：路径与类型、容量边界、拒绝无副作用、缓存失效、非法/过期提案、学习发布回退、输入超长整行拒绝。
2. ARM QEMU 串口真实交互：目录与文件 CRUD、错误输出、AI 决策计数、学习与文件数据一致性。
3. 保留 M1 自检和日志压力测试；构建、格式、clippy、无浮点/SIMD 检查。
4. 最终独立代码审核，修复重要问题后提供可直接启动的入口与手工测试步骤。
