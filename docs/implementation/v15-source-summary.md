## 4. V0.15 的变更与 CI

本次只更新 VERSION、README、来源清单、汇总文档及工作流触发范围，并增加版本归档回归。
保留历史 `v13_*` / `v14_*` 文件名，因为它们是已有工具入口和测试契约，不机械改名。

| 工作流文件 | V0.15 行为 |
|---|---|
| `.github/workflows/validate-prototype.yml` | push / PR 执行完整 Static、Rust、Host、Tools |
| `.github/workflows/v14-a-workstreams.yml` | push / PR 执行 W1–W6，组件状态不能提升原生验收 |
| `.github/workflows/v14-native-a02.yml` | push 执行 A02；相关源码 PR 同样触发；固定工具链与补丁 QEMU |
| `.github/workflows/v15-source.yml` | 校验版本/来源/工作流后归档精确 Git 源码，保存 commit/tree/SHA-256 |

归档成功只表示源码打包成功，不等于其他工作流成功，更不等于全套验收通过。
原生工作流继续把结果写入独立批次目录，不覆写受版本管理的总验收目录，私有身份目录不上传。

统一入口仍为 `python3 tools/prototype.py build|run-single|run-pair|test|report`。
重放先按仓库说明准备固定 Rust/QEMU 与私有身份；完整参数查看相应命令 `--help`。
组件分路沿用 `python3 tools/v14_workstreams.py --lane W1 --output <新目录>`，W1 可替换为 W2–W6。
