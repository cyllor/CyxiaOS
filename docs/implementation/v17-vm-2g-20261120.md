# 2 GiB COSMIC 虚拟机配置

当前测试 VM 使用 2048 MiB 内存、4 vCPU、QEMU TCG、VirtIO GPU 和
1024 × 768 显示。镜像为 `artifacts/v017-os-cosmic-2g-v1`。

原内核只支持 1 GiB 的启动解析、临时映射、内核直接映射和物理页跟踪。
新增显式 `ram-2g` 特性，将这些范围同步扩展至 2 GiB；原 1 GiB 特性默认
值和启动工具保留。用户进程的堆、线程、FD、共享内存等限额保持原值。

2 GiB 启动会从真实 loader 内存图保留一页 1 GiB 以上的 RAM，在受保护
高地址映射安装后执行实际写入 / 读取 / 清零，并输出 `X86_RAM_2G_OK`。
本次验证地址为 `0x40000000`。QMP 实际返回 `base-memory=2147483648`、
`plugged-memory=0`；内核识别 `2146942976` 字节 RAM，差额为固件等保留区。

构建与手动运行：

```sh
python3 tools/os_x86_2g.py build --profile release --graphics --ported \
  --feature cosmic-time-applet-v1 \
  --sysroot artifacts/v017-native-pointer-motion-catalog-v1 \
  --output artifacts/v017-os-cosmic-2g-v1
python3 tools/os_cosmic_manual_2g.py \
  --build artifacts/v017-os-cosmic-2g-v1 \
  --output artifacts/manual-cosmic-2g-20261120-v1
```

输出目录须为新目录。手动启动器核验镜像和实际 QMP 内存后，自动启动
真实 dbus / COSMIC，随后将鼠标键盘交给用户；关闭窗口结束进程和原生锁。
当前窗口的配置记录在 `artifacts/manual-cosmic-2g-20261120-v1/`。

检查：PC 平台 36 项、默认 1 GiB 架构 37 项、2 GiB 架构 37 项通过。
实际内核映射批处理回归通过；原夹具只提取单行声明，已改为提取完整
顶层分号终止的声明，以覆盖新多行静态数组定义。保留初始夹具失败日志。
2 GiB 真实原生烟测为 `OS_NATIVE_PASS`，并验证 1 GiB 以上内存可访问。源码
快照和检查日志位于 `artifacts/debug/vm-2g-20261120/`，实际烟测位于
`artifacts/v017-os-cosmic-2g-native-v1/`。

本次是内存配置与启动验证，未将之前 1 GiB 的性能测量标为 2 GiB 结果。
