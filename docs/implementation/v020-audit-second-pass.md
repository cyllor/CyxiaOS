## 仍开放的正式门
- G0 BLOCKED：生产 CPU0 八角色独立加载、预算/异常/重启/IRQ、CPU1–3 业务隔离。已通过的历史 QEMU 角色夹具并非八个生产服务。
- G1 NOT_READY：新版介质、快照目录与保留、ACL/收据/安全状态原子事务、所有 19 个 ABI 原生接线。先锁定唯一格式，禁止静默重格式化或降低保护。
- G2/G3/G4-QEMU：完整原生六专项、交错、127 ID 与快照专项仍需逐项可追溯执行证据。
- G5-ARCH：实体平台未验收。所有性能改动必须实测，不以静态复杂度变化声称提速。
- D01–D15 等地位，CPU0 单核固定；双脑仅建议，确定性授权和执行、UNKNOWN 保管、恢复额度不放宽。
