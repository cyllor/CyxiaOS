# CyxiaOS V0.18 开发基线

软件版本为 `0.18.0-dev`，分支为 `CyxiaOS-V0.18`。本版汇总
`CyxiaOS-V0.17@d7fb19a6a09c960251a3e6ad071a1af46a0f7a27` 的已提交代码。
主开发平台为 x86-64，镜像验收使用 1 GiB、4 vCPU。规范 1.3 的独立验收状态见
[原型要求目录](../implementation/v13-requirements.json)。

## 主要改动

| 范围 | 已合入的实现 |
| --- | --- |
| 启动和容量 | 按检测到的 RAM 和在线 CPU 计算进程、线程与内存准入额度，启动日志报告实际容量。 |
| 页表与授权 | 复用进程根页表并增量更新。批量撤销时合并别名锁与纪元更新，容量不足时回收空表。Grant 与 redemption 使用 ID 推导的槽位，并验证完整身份。 |
| 调度和 I/O 等待 | 原地唤醒线程，按事件和截止时间复用等待状态。epoll 按源查找监视项并增量传播嵌套边沿。稳定的 poll 跳过后端重采样，timerfd 使用最小堆追踪到期。 |
| 设备与文件持久化 | VirtIO 批量 RX 直接从 DMA 缓冲区拷贝到调用方。内容一致时复用已落盘的 checkpoint，数据发生变更时执行两次设备 FLUSH。 |
| COSMIC | 汇总合成器、面板、时钟、通知、壁纸、工作区、平铺和应用库移植，并保留与其对应的会话输入、对象容量及资源回收验证。 |

容量与各项优化的设计背景见
[V0.17 容量设计](../implementation/v17-system-capacity-design-20261121.md) 和
[内核算法交接](../implementation/v17-algorithm-optimization-handoff-20261122.md)。

## 本地回归

- 工作区 Rust 测试通过 1,612 项。POSIX COSMIC 配置、x86 页表运行时专项和 x86-64、AArch64 内核编译检查通过。
- x86 的 1 GiB、4 vCPU 镜像通过 17 个客体场景，覆盖 Wayland、并行派发、线程和堆容量、PTY、timerfd、嵌套 epoll、inotify、FD 共享及两种 fsync 的重启回读。
- COSMIC 在 45 秒检查点已替换启动画面。构建使用 185 项已验证的移植输入，镜像摘要与 V0.17 基线镜像一致。

本地证据目录为 `artifacts/v018-validation`。源码归档、引导镜像与校验清单位于
`artifacts/v018-release`。

## 后续开发：不可变日志快照

在 `e9442cd7ffb56373ca180beb532e99aa4a736385` 基线上增加日志文件系统 v2：
业务数据、目录和间接 extent 使用 CoW；历史句柄只读；恢复只切换业务根并失效旧 LIVE
能力；请求去重、保护状态、保留期限与系统记录不随业务恢复回退。GC 验证全部保护根，
经两次检查点和设备静止确认后才复用块。详情见
[实现与迁移说明](../implementation/v18-immutable-journal-snapshots.md) 和
[原生文件服务协议](../implementation/v18-snapshot-file-abi.md)。

这项功能接入原生 prototype 日志文件服务；桌面 RAMFS 的 checkpoint 路径保持独立。
v1 卷不能直接可写挂载为 v2，已有数据需要离线导出到新的 v2 设备。
当前工作区 Rust 回归通过 1,661 项，37 项专项 Python 检查通过，双节点 AArch64 原生镜像
与 EL0 快照探针链接成功。固定 QEMU 的完整联机测试已经执行，但最新运行在既有网络
IPC 发送段触发 CPU 预算超限，尚未完成整条快照流程；额度与隔离规则保持不变。
同一镜像隔离节点网络后的本地验证也在网卡空队列处理和 CPU1 控制任务触发预算超限，
原生快照端到端验收仍未通过。这些结果不替代原生断电与最大脏页时延验收。
上节的 1,612 项和 x86
客体证据属于原开发基线，不能视为这次快照变更的原生执行证据。

## 已知验收边界

V0.17 的 AArch64 网卡单拷贝专项确认双客体持续回收 RX 描述符。两客体 TCP 联合回归在
单线程和多线程 TCG 下达到 90 秒截止，单线程基线也超时。该验收项仍待通过。

COSMIC 的首帧检查验证会话启动后 45 秒检查点上的客体画面。应用交互和日历响应仍按各自的
验收场景记录。当前软件基线的 x86 证据使用 TCG。
