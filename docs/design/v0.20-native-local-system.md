## 2. 平台与可信边界

AArch64 Cortex-A53、QEMU virt、4 vCPU、1 GiB RAM。目标核心集合固定为 C={CPU0}、B={CPU1,CPU2,CPU3}；普通业务只在 B 上运行，控制面 EL0 角色只在 C 上运行。EL1 提供共享确定性机制。CPU0 失效时停止新的控制发布，保留在途义务并由确定性安全路径收尾，不从 B 动态选取替代控制核。

运营 AI 大脑与安全大脑在唯一控制 CPU0 上分别运行于独立原生 EL0 保护域，独立身份、代际、页表、模型、工作区、队列及子预算。确定性控制器独立授权和裁决，唯一发布代理提交，EL1 与受保护执行器实施；模型不具有最终安全拒绝豁免、资源授予、页表修改、快照删除/恢复/解冻或执行权。安全发现仅请求复核，确定性机制依据真实证据与离线预授权规则决定保护行为。无 AI 时业务及安全门仍正常工作。

本原型不提供集群成员管理、跨机资源共享、远程执行、D16 或动态控制核伸缩。正式异构集群成员将来须原生运行 CyxiaOS；不能以宿主 OS 上的代理代替。x86-64 实现应独立登记平台适配和证据，不以 ARM QEMU 结果代替。

## 3. 唯一控制预算与计账

以客体单调时钟对齐的 100 ms 为窗口，CPU0 控制预算合计不超过 70 ms：

| 项目 | 上限（ms/100ms） |
|---|---:|
| 运营 AI 编码/推理/建议 | 30 |
| 独立裁决/核验/发布 | 7.5 |
| 协调/遥测 | 8 |
| 确定性恢复保留 | 8 |
| 安全大脑辅助分析 | 8 |
| 可选训练/验证/Shadow/Canary | 8.5 |
| 合计 | 70 |

未承诺余量 30 ms；每业务核硬承诺最多 90 ms，另留 10 ms IRQ/维护。所有角色共用唯一控制账本，不因模型切换、重启或新增安全功能重复计算预算；实际超限记录退化并停止新优化。8 MiB 控制池、8 MiB 进度池及 10 MiB 全局 FrameMeta 预留按 V0.19.9 计账，不隐性扩容。快照保护、文件 COW 与 GC 另按真实业务/进度资源预留和计账；不得侵占最后恢复额度。

## 4. 十五领域 AI 同等接入

D01 调度、D02 进程、D03 内存、D04 文件、D05 IPC、D06 中断、D07 定时器、D08 系统调用、D09 I/O、D10 网络、D11 设备、D12 安全与隔离、D13 背景能耗代理、D14 诊断恢复、D15 HAL/串口。所有领域具有同等架构地位。不可变快照是 D04 的文件持久机制，与 D12 安全保护协同；不新增资源动作族。

统一链路：受保护快照 → 辅助建议 → 独立规则允许集合和确定性回退 → 独立裁决 → 唯一发布 → 真实执行回执 → 反馈。D06/D11/D12/D14 安全敏感动作只走独立确定性规则或受保护试验许可；D10 发送调度执行器在 EL1，与 TLS 解析器/验证器隔离。业务热路径不等待模型。

Schema 对象独立版本化：FeatureSchema v3、ActionSchema v2、RewardSchema v2、LearningConfig v2、RuleProfile v2、AdviceEnvelope v1、DecisionSchema/DecisionRecord v3、PlanHeader/PolicyEnvelope v2，具体完整契约见基线。现有 19 个系统调用号不因快照增补而增加；快照控制使用既有本地 service_call 的版本化端点，权限及封包在 G1 核定，不复用历史 SVC 编号造成歧义。

## 5. 六专项与文件保护

| 专项 | 确定性安全执行点 |
|---|---|
| SEC-P | 可信装载、任务/能力代际、固定 CPU 归属、生命周期 |
| SEC-F | 文件能力与 ACL、事务/FLUSH、票据/去重、不可变历史根、恢复与回收 |
| SEC-M | W^X、页所有权、软件 PAN、BBM/TLB、DMA pin、清零 |
| SEC-N | 原生 TCP/TLS、独立限流及身份核验、有界连接与缓冲 |
| SEC-D | VirtIO 协商、描述符和完成证据、可靠复位、IRQ 路由 |
| SEC-S | 入口有界复制、真实调用者身份、授权原子门、唯一发布与执行回执 |

文件系统须同时具备 redo 崩溃一致性和不可变历史版本保护；redo 不是快照。普通合法 WRITE/UNLINK、AI 建议、容量压力或恢复超时均不得破坏受保护的历史根。新镜像格式、旧卷兼容、ACL/收据/保护状态不回退、快照 GC 的事务与资源证明，按候选增补的 G1 决议完成。禁止以旧卷直接重格式化或静默放宽保留期满足测试。
