# V0.20 G0 基线复审与冻结

按现行安§7.2 与安§0.10 复审，G0 的基线冻结条件已满足。六专项采用同一规范摘要
`895d464908bced980bae31af30c36866d1f3812f94939db15ad9ca8193749302`。
冻结内容来自 `3260c3de0d6e7bad87f144a65b789f1d2324a2f8`。复审核对了登记参数、现行范围、
系统调用表、控制角色契约和验收清单。[分级门槛](baselines/v0.19.9-implementation-spec.txt#L10892) · [规范来源锁](v0.20-g0-baseline-lock.json)

## 规范及范围

- V0.19.9 现行实现规范全文是共同基线。V0.20 原生单机设计第 1–5 节给出目标架构，第 7 节给出验收要求。
  共享的主控拓扑为 CPU0，业务核为 CPU1–3。CPU0 的两个隔离大脑各自只具备辅助建议或发现资格，裁决和发布由相应独立角色承担。
  [设计正文](v0.20-native-local-system.md#2-平台与可信边界)
- 不可变快照纳入 V0.20。介质采用已批准的策略 A，保持 v1 超级块字节，签名统一卷从四个系统对象扩至八个。
  v2 旧卷采用离线只读导出、全零新卷重建及验证连续性的导入路径。文件和快照端点共享既有 `0x50` 调用入口，按各自端点资格与封包处理。
  19 个 ABI3 调用号按照基线表逐项保留。[策略 A](v0.20-g1-media-freeze.md)
- 127 个稳定 ID 的 262 个 G4 证明键保留原归属，包括 127 项运行、51 项静态 EL1 与 84 项模型检查。
  26 个实体 `ARCH_A53` 证明键进入 G5。V0.20-SIM 对应的 26 项模拟器软件义务和七组快照断言也都保留。
  [证明清单](../../tools/v0199-required-proof-inventory.json) · [已批准 SIM 范围](../implementation/v020-sim-acceptance-scope.md) · [SIM 映射](../implementation/v020-sim-proof-scope.json)

## 参数拥有者与专项交接

安§0.10 的 135 个已登记参数键分属 22 个拥有者。逐行复审已登记条目的归属和基准，核对到每键唯一拥有者。
`SecurityProfile v3` 的安全限额走各字段的偏移和长度引用。执行器与检查器使用同一锁定 Schema 和参数；下表说明各专项使用的主要权威。
[参数注册表](baselines/v0.19.9-implementation-spec.txt#L7818)

| 专项 | 主要参数权威 | 跨域须保留的义务 |
|---|---|---|
| SEC-P 进程 | `PlatformSchema.v1` 的平台和控制核、`ResourceSchema.v1` 的任务与 CPU 额度 | 退出关新派发。引用、映射和已受理事务分别由实际所有者结算 |
| SEC-F 文件 | `FileFormat.v1`、`FileServiceRequest.v4`、`FileAuth.v3` 及批准的策略 A | 持久文件真值以实际日志和提交证据确认。恢复保持授权、历史与收据连续性 |
| SEC-M 内存 | `PlatformSchema.v1` 的页与入口、`ResourceSchema.v1` 的 FrameMeta 与 BBM 资源 | 旧页使用权在 M 核对 TLB ACK 后才进入回收；设备 DMA 停止另由 D 证明 |
| SEC-N 网络 | `TcpSchema.v1`、`TlsSchema.v1`、`EchoSchema.v1`、`CSPRNG.v1` 和 `NetworkTestSchema.v1` | 代际切换和已认证请求排空分别保留证据；设备缓冲继续遵守 D 的 DMA 所有权 |
| SEC-D 设备 | `PlatformSchema.v1` 的平台、`ResourceSchema.v1` 的队列限额及 `ActionSchema.v2` 通知动作参数 | 只有完成记录或可靠复位证明可解除 DMA 保管 |
| SEC-S 系统调用 | 主 §2.2 的 ABI3，`Verdict.v4`、`SecurityAudit.v2` 和 `RecoveryProof.v2` 各自的证据字段 | 入口核验真实调用者、能力和版本。副作用与线性化点由目标子系统确认 |

## 复核命令

```sh
python3 -B tools/verify_v020_g0_freeze.py
```

校验器重算每个规范片段的 SHA-256，再对按源名称排序的紧凑 JSON 摘要映射计算共同摘要，域标签为
`CYX/G0/V0.20/v1`，后接一个零字节。固定片段涵盖现行设计和
批准决议。实现历史、验收状态行及归档进度可继续更新。校验同时核对参数唯一归属、拓扑、双脑静态资格、
19 个调用号和逐用例证明类别。记录的通过结果属于 G0 设计审查。[校验器](../../tools/verify_v020_g0_freeze.py)
