## Review Focus

1. Wrong/missing firmware identities or stale ACKs must prevent CPU admission and ownership transfer (Task 1).
2. Halt, sibling execution, clock failure and cross-CPU stamps must not create valid CPU credits (Task 2).
3. Cross-ISA images, address aliases, FP/TLS contamination and premature TLB/page reuse must fail closed (Tasks 3–4).
4. Device lengths, DMA ownership, interrupt completion and persistent recovery must retain existing safety semantics (Tasks 5–6).
5. Captures from a different source/model/boot/accelerator or an untrained Active claim must not pass independent verification (Tasks 7–8).
