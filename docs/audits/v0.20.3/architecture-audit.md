### A203-001 — 批量块设备缺少本次 status 写入仍可报告成功

- **领域/类型：** HAL / 设备 / 文件可靠性 / implementation_defect。
- **符合性/证据/等级：** 原版本不符合；当前组件范围符合；已证实并复现；P1。
- **要求：** SEC-D 完成证据；SEC-F WRITE/FLUSH 完成语义。
- **成立条件：** 设备写入完整 used 长度，但没有写 status；新槽或复用槽原有的 0 被解释为成功。
- **影响：** READ/WRITE/FLUSH 可错误报告成功并推进完成版本。
- **证据锚点（基线）：** `crates/driver-virtio/src/block/batched.rs:158-166,215-231`；`crates/driver-virtio/src/queue.rs:323-325,573-585`。
- **整改目标：** 在槽仍由 CPU 私有持有时，将 status 尾字节置为 0xff，再同步并发布 DMA；其他队列调用保持原接口。
- **关闭判据：** Read/Write/Flush × fresh/reused 缺失 status 均拒绝；输出及成功版本不变，错误 token 不能 ACK，DMA 不被释放。
- **本轮证据：** V03, V04, V08, REVIEW-01。
- **边界/反证：** 关闭限源码及宿主故障注入组件；真实设备故障注入另列 VG03。
- **参考已有修复：** `4c49f2380d44315f695edaf7b5330c407b7a7d01`；本次为语义最小移植，保留V0.20.1优化。

### A203-002 — 复位与提交失败后块设备未完整锁存失败

- **领域/类型：** HAL / DMA 所有权 / 可靠性 / implementation_defect。
- **符合性/证据/等级：** 原版本不符合；当前组件范围符合；已证实并复现；P1。
- **要求：** SEC-D 设备状态与可靠复位；SEC-M DMA 保管。
- **成立条件：** 提交前复位、队列提交失败，或队列取得 completion 到 IRQ ACK 期间失去 DRIVER_OK。
- **影响：** 旧完成可能报告成功；外层 owner 仍可能触碰被隔离的 DMA。
- **证据锚点（基线）：** `crates/driver-virtio/src/block.rs:93-101,125-175`；`crates/driver-virtio/src/block/batched.rs:203-232`；`crates/driver-virtio/src/queue.rs:546-563`。
- **整改目标：** 单请求进入前检查就绪状态，submit 错误粘性锁存，单/批量完成取得后再次核对状态；失败保留 DMA 保管。
- **关闭判据：** 复位前提交/复位带旧 used/ACK 窗口复位/submit 错误均拒绝；设备状态表面恢复不能解除失败锁存；不复制输出、不推进成功版本。
- **本轮证据：** V03, V04, V08, REVIEW-01。
- **边界/反证：** 关闭限本次实现与宿主反例；不声称真实 DMA 时序或硬件复位全部验收。
- **参考已有修复：** `687dbae3f77ad09a08875b44b8d5a6915e65b9f4`, `0d12dd53a04f07a00e278e558473ab8434b0dc22`；本次为语义最小移植，保留V0.20.1优化。

### A203-003 — 已冻结终态的安全 Finding 仍可重新触发复核

- **领域/类型：** AI 辅助安全 / 状态机 / 审计 / implementation_defect。
- **符合性/证据/等级：** 原版本不符合；当前组件范围符合；已证实并复现；P2。
- **要求：** V0.19.9 § 安全 Finding 有效目标及最终处置幂等。
- **成立条件：** reserve Assisted → submit → finalize InvalidTarget → 原有效期内 consume；此前仅检查 consumed。
- **影响：** 终结建议重新进入待复核工作，破坏终态一致性；不直接授予动作权限。
- **证据锚点（基线）：** `crates/kernel-core/src/control_plane/security_finding.rs:491-534,553-598`；`docs/design/baselines/v0.19.9-implementation-spec.txt:5570-5574,5602-5604`。
- **整改目标：** consume 同时拒绝 consumed 或存在 terminal 的记录。
- **关闭判据：** ACK 前后 consume 均返回 Stale；终态字节不变，未 ACK 保留 credit，ACK 后也须 context 到期才回收。
- **本轮证据：** V05, V06, V08, REVIEW-02。
- **边界/反证：** 当前完整 FindingCustody 尚未接入生产入口；没有据此声称已发生原生攻击。

### A203-004 — x86 os-runtime 豁免不兼容的 ARM production 特性
